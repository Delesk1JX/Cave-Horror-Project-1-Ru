# Cave-Horror-Project-1

Информация: Перевод квестов в сборке Cave Horror Project 1 (3.2.3a+) Ссылка на [сборку](https://www.curseforge.com/minecraft/modpacks/cave-horror-project)

Установка: Пример для Prism Launcher:

Скопировать с заменой файлы в корневую директорию модпака. Например, C:\Users\user\AppData\Roaming\PrismLauncher\instances\CHR1\minecraft

После запустите игру и проверьте работу перевода.

Для перевода модов использовал [RTF Extension](https://modrinth.com/resourcepack/rtf-extension)

Если найдёте какие-то ошибки, можете сообщить о них мне в дискорд: narik_20
